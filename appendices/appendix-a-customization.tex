\section{Changing the Page Format}

The template is designed for portrait A4. To use US Letter, replace
\texttt{paper=a4} by \texttt{paper=letter} in \file{main.tex}. To change the
margins, adjust the values of \pkg{geometry} in the style file. Landscape is
also possible: add \texttt{paper=landscape} to the class options and revise
the margins.

\section{Changing the Language}

English is the main language and Spanish is also loaded (see
\cref{sec:spanish}). To make Spanish the main language, change
\texttt{main=english} to \texttt{main=spanish} in Section~2 of the style file.
To add another language, load it in the same \pkg{babel} line and translate the
captions of the callout boxes and the word \enquote{References} next to the
existing \cmd{addto} lines.
